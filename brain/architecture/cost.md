# Cost readers and pricing

Costs are read from the transcripts the CLIs already write and rated against
LiteLLM's price table; ccusage is the fallback and the cross-check, not the
source. The regression rules and the five traps are also in `CLAUDE.md` ("Costs
are read, not shelled out for"). User-facing figures:
[../features/cost-tracking.md](../features/cost-tracking.md).

## Readers

`crates/tokengauge-core/src/cost/` holds one reader per transcript tree:

| Reader | Tree |
| --- | --- |
| `claude_code.rs` | `~/.claude/projects` (through `claude_config_dir()`) |
| `codex_cli.rs` | `~/.codex/sessions` |
| `kimi_cli.rs` | `~/.kimi-code/sessions/**/wire.jsonl` and `~/.kimi/sessions` (`KIMI_DATA_DIR` overrides) |
| `grok_cli.rs` | `~/.grok/sessions/**/updates.jsonl` |

Every reader emits the same unit, a `UsageEvent` (`provider`, `model`, `date`,
`at`, `tokens`, `key`, `one_request`), so **a new CLI is one more reader**: add a field to
`cost::Roots` (filled by the reader's `roots()` in `Roots::discover`, listed in
`Roots::all`), call the reader from `read_events_from`, flip its
`ProviderMeta.natively_read` (below), and `build_report` does the rest. A fetch reads from `cost::window_start` (the start of the month,
widest re-read 31 days) through `read_window`; `read_history` is the one-time deep
read behind the backfill (see [../features/spend-history.md](../features/spend-history.md)).
`jsonl_files` leans on an mtime filter that a deep read defeats, so the deep read
never runs on a poll.

`Roots::unreadable` lists the roots that exist and cannot be read (any
`read_dir` error but `NotFound`). `jsonl_files` reads such a root as no files,
and the fleet store, replacing a provider from the oldest event the other
roots still found, would drop every day only it held, so the sync layer keeps
this device's record instead ([sync.md](sync.md#the-fleet-store-is-the-durable-record)). A root that
does not exist is a CLI never used and reads as empty.

`ProviderMeta.natively_read` marks the providers with a reader (codex, claude,
kimi, grok). It gates fleet sync and the `--doctor` drift check; flip it when a
reader lands.

## The five traps

Each has a test named after it:

- A **streamed message is written repeatedly**, each record restating
  `(message.id, requestId)` with more `output_tokens`. A duplicate upgrades the
  event; keeping the first loses 46% of some models' daily output.
- Codex `total_token_usage` is **cumulative for the session**; its delta is the
  billed unit. `last_token_usage` re-fires with the cumulative unchanged.
- Codex `cached_input_tokens` is **inside** `input_tokens` (Anthropic reports
  cache reads beside them); Grok's `cachedReadTokens` / `cacheCreationTokens` are
  inside `inputTokens` the same way.
- A Kimi `usage.record` scoped to the **session** restates the running total;
  only `usageScope: "turn"` is a billed call.
- Grok's per-turn `usage` totals are the **sum of its `modelUsage` map**; taking
  both bills every turn twice.

## Pricing

`pricing.rs` fetches LiteLLM's table, caches it beside the snapshot
(`tokengauge-prices.json`), and vendors `prices.json` for a cold or offline
machine (regenerated by `scripts/make-prices.py`).

- The table is served 24h without asking. `refetch_for_unpriced` treats tokens
  with no price as proof the table is behind and buys one download outside the
  freshness window. The unpriced set is recorded
  (`tokengauge-prices-missed.json`) so a model upstream never carries cannot turn
  every fetch into a re-download.
- A transcript names the bare model; LiteLLM keys by seller (`zai/glm-4.6`,
  `xai/grok-4`, `moonshot/kimi-k2-thinking`). `price_candidates` walks from one to
  the other and `attribute_price_key` mirrors it to decide what the vendored table
  carries; the two must agree. A provider sold under another namespace needs a
  `vendor_prefixes` entry, or it is rated at a zero that hides itself.
- **Price archive** (`price-archive.json`): sparse per-month `PriceOverride`s,
  only for prices a vendor moved, merged field by field onto today's entry. Built
  by `scripts/make-prices.py` from LiteLLM's git history. See
  [../features/spend-history.md](../features/spend-history.md#a-past-month-is-rated-at-a-past-months-prices).
- **Long-context tier** (`ModelPrice.long_context`, a `LongContext`): LiteLLM's
  `<field>_above_<N>k_tokens` prices, the lowest threshold that reprices input
  (service-tier suffixes such as `_priority` are ignored). `cost_of_request`
  bills every token of a request whose prompt (input plus cache reads and
  writes) ran past `above` at the tier, a zero tier price falling back to base.
  It applies only to a `UsageEvent` with `one_request`: a Claude message and a
  Codex rollout response. A Kimi or Grok turn, a `codex exec` row and a fleet
  bucket are several requests summed and stay at the base price, so history
  and the device split can read a little under the row on a long-context day,
  never over it. Token counts are untouched, so ccusage parity holds.
  `make-prices.py` keeps tier fields in `prices.json` and leaves them out of
  the archive (history rates per bucket); the vendored `prices.json` in the
  tree predates this and carries no tiers until regenerated, so only a fetched
  table is tiered. The rule is in `CLAUDE.md`.

## ccusage

`cost_source` picks `auto` (default: native, asking ccusage only about enabled
providers the readers found nothing for, such as a GLM plan driven from z.ai's
own CLI), `native` or `ccusage`. `ccusage` is found on `PATH` (global, then
`bunx`, then `npx`).

Token counts must match ccusage exactly. Three checks at widening cost:
`crates/tokengauge-core/tests/cost_fixture.rs` diffs the readers against a
checked-in ccusage golden (CI), `cost::tests::agrees_with_ccusage_on_real_transcripts`
(`#[ignore]`d) does it on the developer's home, and `--doctor` does it on a
user's machine (local slice only when fleet sync is on). Regenerate the fixture
with `scripts/make-cost-fixture.py`: emit **compact JSON** (ccusage prefilters by
string match) and **compare token counts, never days or money**. The generator
refuses a fixture that stopped covering the traps.
